## 全站缓动

### 滚动阻尼（`damping.js`，三个页面都挂）
- 滚轮不再直接滚页：它推的是一个**目标位置**，页面每帧由**临界阻尼弹簧**（`OMEGA=13, ZETA=1`）追过去，起步利落、收尾没有过冲。
- 单次滚轮的位移上限 `MAX_STEP=260px`，避免一格甩太远。
- 优先级：**已经 preventDefault 的手势不再接管**——在委托屏上滚轮归轮播；被别处移动的滚动（锚点、键盘、封面过渡里的 `scrollTo`）会**重新对齐目标**而不是被拽回来。
- 关闭方式：`prefers-reduced-motion: reduce` 自动禁用；单个容器可加 `data-native-scroll` 保持原生滚动。
- 内部锚点（`a[href^="#"]`）也走同一套缓动落点。

- `rise.css` + `rise.js`：三个页面共用的入场缓动。按选择器给区块加 `.rise`（`opacity/translate/blur`），用 `IntersectionObserver` 在进入视口时加 `.is-in`，错峰间隔由 `--rd` 控制（同一组最多 360ms）。曲线统一用 `--ease-soft`，与封面/牌堆同一套；`prefers-reduced-motion` 下直接跳过。
- `veil.css` + `veil.js`：`collection.html` / `achievements.html` 的页面转场（`index.html` 由 `main.js` 驱动同一套 `.page-veil`）。点击同源 `.html` 链接时两片黑帘合拢再跳转，落地时先合拢后展开；跨页用 `sessionStorage.ncl:transition` 传递“正在到达”。
- 现有 `transition` 已统一带曲线（`var(--ease)` / `var(--ease-out)` / `var(--ease-soft)`）；子页面若没有这些变量，`rise.css` 内置了回退曲线。

### 02 定制（一次一张，右侧待看列表）

- **扉页到这一屏**：封面 `position: sticky` 钉住，`.bespoke` 用 `margin-top:-100svh` 从下方盖上来；覆盖过程中（p 0→1）封面 `blur(0→10px)`、压暗 42%、轻微后退 `scale(1→1.04)`。纸面顶端用 104px 黑色渐变过渡，没有硬边。
- **左侧阴影单独走慢时钟**：`.deck-copy::before` 不再跟着文案一起 0.3s 淡入，而是由 `.is-primed` 状态驱动 `opacity` 过渡——预置时瞬隐（`transition:none`），开卡时开始 **1.6s** 的缓入，开卡那 0.62s 的类移除也不会打断它；收场时 0.25s 快速消失。
- **进场编排（GSAP + deck 自身动画）**：`intro.js` 只负责黑幕：下滚 8px 触发，**0.36s 升起铺满视口**（`power2.out`）。过渡层里**只剩黑幕**（旧的 `.di-card` 已删除：它在黑幕之上，会在整段过渡里盖着一张满屏图）。**黑幕铺满的那一刻，页面在黑幕底下直接移动到委托屏**（不用再滚 800px），然后黑幕 0.13s 淡出，同时给 deck 派发 `ncl:deck-open`，由 deck 自己按顺序演：**先把当前卡预置到它的缩略格**（`ncl:deck-prime`，黑幕还在时瞬移，不播过渡）→ **列表先在**（右侧缩略格是静态的）→ **当前卡从它的缩略格位置长到画框**（`.34s`，圆角 16→0）→ **左侧文案最后淡入**（延迟 `.34s`，`.3s`）。另外 `.sheet:nth-child(1)`（背卡）设为 `opacity:0`——它只用来让换卡时「下一张已在后面」，若可见，开场时会整屏露出上一张。离开时反向：`ncl:deck-close` 先让卡片缩回缩略格、文案淡出，黑幕再升起退回扉页。
- **为什么是 ease-out、为什么不等 18%**：这两处原来都会让人觉得"卡住了"。触发阈值在 18% 视口高时，前 160px 只有封面在变暗、黑幕完全不动；`power2.inOut` 又让面板前三分之一的时间里几乎没离开底边。现在实测：下滑 20px 后 107ms，面板已经走了 25%；761ms 铺满；卡片从 761ms 才开始淡入，1.10s 全亮（`review/pacing/curve.jpg` 是三代缓动的对比与实测点）
- **过渡期间委托屏不露头**：黑幕是从底边升起的，升起来之前那一小段时间，下一屏（`.bespoke`）已经随滚动从底边探进视口。所以只要过渡在进行（`body.is-intro`，`y > 2px` 即生效），委托屏一律 `visibility:hidden`；交接的那一帧再放开——两边的第一张卡是同一张图、同一条裁切，看不出来
- **交接**：只有 `.bespoke` **钉住的那一刻**（`y ≥ deckTop`）才 `progress(1)` 收尾并淡出整层。更早交接会让 deck 比最终位置低 400 多 px——卡片跳一下、右侧待看列表还在屏幕外，看起来就是"第一张图又出现了一次"。判定是**位置优先**的：一次性大幅跳转（锚点、PageDown、恢复滚动位置）只派发一次 scroll 事件，也能直接落到正确状态
- **卡片几何对齐**：过渡层里那张照片不是铺满视口，而是 deck 的**舞台盒**（引擎每次绘制发布 `--card-l/t/w/h`，即中间那一列的矩形）；交接那一帧再直接读一次 deck 展开卡的实测矩形，所以交接前后是同一张图、同一个裁切、同一个位置，只有 deck 自己的界面（左侧文案、右侧轨道）在此刻出现
- **反向**：从 deck 往上滑，越过 `deckTop − 2%vh`（刚解除钉住）时开始反向；**正向播到一半就往上滑也一样**——只要回到扉页区（`y < 0.18vh`）就立刻反向，不会把层冻在半路。反向时先把时间轴拨回 `progress(1)` 再 `reverse()`——照片先淡出（0.72s），黑幕再回落（1.05s），扉页干净回来；`onReverseComplete` 收掉整层。方向切换有回差（`0.45vh` / `0.55vh`），不会来回抖；反向中途再往下滚会继续 `play()`
- **实现位置**：静态站 `home/intro.js`，React 版 `react/src/lib/useIntro.js`（封面组件的 hook），与 deck 引擎解耦
- **黑幕升起（CSS 动画，0.62s）**：页面往下动一点点（`y > 8px`）就给 `.deck-veil` 加 `.is-filled`，面板由**合成层动画**从视口下方升到 0（不再用 rAF 计时，后台标签页的 rAF 节流会让它慢十几秒）。面板是纯黑实体，顶边的柔化交给 `box-shadow`，所以**升满后整个视口全黑**（连导航也压住，因为它是 body 根层的 `position:fixed; z-index:1000`）
- **退回去**：滚回扉页时 `retract = (sectionTop − y) / (0.6·vh)`，幕布重新降到视口下方，扉页干净可见；只有真正到过 deck（`t > 0.02`）才启用，所以第一次下滑不会把幕布收走
- **黑幕退开（跟滚动）**：进入委托屏之后，`lift = t / 0.5`，幕布继续向上移出（`translateY(0 → -100%)`），卡片和右侧列表就在幕布后面被逐段揭开；往回滚会落回来
- **一次只展开一张**：`index = floor(进度 + 0.02)`，只有这张铺满画面；其余按顺序停在右侧列表里，所以**第一张展开时列表是满的（7 张），最后一张展开时列表为空**。
- **中列舞台（桌面）**：展开卡不再铺满视口，而是落在**左侧文案**与**右侧待看列表**之间——横向 `[copyW + 30, vw − pad − railW − 30]`，纵向**相对视口镜像留白**（`clamp(56, 8.5vh, 120)`），所以卡片是视口垂直居中的、不是挂在导航下方的 deck 盒子里；
卡片直接铺满这个盒子，`object-fit:cover` 只裁掉约 17% 的高度。宽度跟着 `railW` 走，所以卡片恰好居中在真实的空档里；右侧轨道整列也以同一条中轴居中（`railTop = coverY − railSpan/2`），不再从顶部挂下来；下一张卡**始终**排在画框下方（`frac=0` 时也不再回落到列表顶部多占一格，否则整列会比卡片高半格）；`--band` 是 `clamp()`，`parseFloat` 取不到值——现在改读 `.deck` 解析后的 `top`，否则 1080p 下会整块偏低 20px。手机端文案在底部，没有左栏可让，仍保持原来的满幅处理
- **推进（参照 3D 轮播）**：大卡缩进列表**末尾的下一位**并淡出（`frac` 前 62% 保持不透明，之后 30% 淡出），下一张**早就在同一位置、同尺寸地叠在后面**（z 900 / 880），所以它是「被露出来」而不是「被推上来」；列表同时上移一格。每次换卡，左侧文案重播一遍模糊上浮（`.deck-copy.is-swap`，0.46–0.5s）
- **滚动闸门（快速滑动不再跳过）**：钉住时任何越过这一屏的位移都会被**按比例兑换成卡片轮播**（`220px ≈ 1 张`），然后把页面按回 `deckTop`——所以甩一把的效果是「快速轮播」，而不是直接飞过。闸门靠**跨越**上膛（上一帧 `y` 与当前帧分处 `deckTop` 两侧即算到达，不要求恰好落在某个窄带里——一次甩动可以一帧从 600 跳到 1500，原先的 ±8px 判据根本不会命中，这就是之前仍会跳过项目页的原因），所以从工艺段或扉页滚过来不会被瞬移；只有轮播到达两端之一，页面才被放行。
- **拦截挂在 document 上**：滚轮监听不能绑在 `.deck` 上——扉页时指针在封面上、工艺段时在工艺段里，都收不到事件，所以以前那两处根本不拦截（快速下滑会直接跳过这一屏，从下一页往上滑也直接回扉页）。现在按**滚动位置**判断，任何位置都能接住；边界只在**已经钉住**（`|y − deckTop| ≤ 4`）时才放行，还没到位的手势属于“到达”，会被吸附过来。
- **开场不会再有空位/黑屏**：八张房间图改成 `loading="eager"`，并且 `ncl:deck-prime` 时对所有 `<img>` 调 `decode()`，解码完成前不揭幕（最多等 900ms）——之前懒加载没到位时，右侧列表会出现空档、画框是黑的。
- **画框底图**：`.deck-glow` 放当前卡的模糊副本（`blur(30px) brightness(.42)`），卡片从缩略格展开的那 0.6s 里画框不是黑洞；它每帧跟随 `syncGlow()` 更新，始终跟当前卡一致。
- **离场不会露出半个 deck**：收场动画结束时不滚动页面，而是派发 `ncl:deck-leave`；`intro.js` 先把黑幕升起（这段时间页面被按在 `deckTop` 不动），黑幕完全盖住后才 `scrollTo(0,0)` 再让它退去——所以不会出现「牌已收起但页面已经滑走、deck 被压暗挂在半空」的一瞬。没有黑幕时间轴（直接落在这一屏）时也走同一条帘幕路径。
- **版式**：`.deck` 现在从视口顶端开始（`inset:0 0 30px 0`），展示时卡片上边缘正好贴住视口顶部；右侧缩略卡的纵向间隔抽成了变量 `--rail-gap: calc(var(--th) + 24px)`——一个槽位 = 一张卡 + 24px 净间距，所以列表永远不相叠、也不会因为视口变窄而挤在一起；毛玻璃底托的高度同样按这个变量算。
- **右侧列表是线性序列，不是循环**：`syncCarousel()` 会给已看过的卡（`data-i < 当前`）加 `.is-past`（`opacity:0`），所以越往后列表越短，**到最后一张时列表与毛玻璃底托一起消失**（`.deck.is-empty`）；往回轮播时会重新出现。
- **卡片只在自己的层里轮转**：8 张 `<figure>` 现在放在 `#deck-stage` 里，`rotate()` 只动这一层的节点；`.deck-rail` 和 `.deck-glow` 是它的兄弟节点，`nth-child` 序号永远稳定。（之前它们和卡片同层，每次 `appendChild` 都把卡片排到它们后面，几次轮播后玻璃/底图就顶替掉了一个缩略格 → 右侧空位、画框变黑。）
- **右侧列表的毛玻璃底托**：`.deck-rail` 是一块 `backdrop-filter: blur(20px)` 的圆角面板，层级在**大卡之上、缩略卡之下**（`.sheet` 3 / `.deck-rail` 2 / 前两张卡 1），把列表和背后的照片隔开；它的位置按缩略格的中心计算（`top: 20% − 卡高/2 − 间距`），与 `--tw/--th/--rail-pad` 同源，换尺寸不会错位。
- **轮播（完全照参考的实现）**：卡片位置全部由 CSS 的 `nth-child` 决定——第 1、2 张同尺寸叠满画框，第 3–5 张在右侧竖排，第 6 张往后停在队尾且 `opacity:0`。换卡就是对 DOM 的一次轮转（`next` 把第 1 张 append 到队尾、`prev` 把最后一张 prepend 到队首），所有位移由同一条 `transition: .5s` 完成；第 2 张始终是「当前卡」，左侧文案跟着它走并重播模糊上浮。底部有 prev/next 按钮，滚轮与拖拽也能换卡。
- **列表卡片的悬浮与跳转**：缩略卡 hover 时上浮 10px、放大到 1.04 并加深投影（`.sheet:not(.is-stage):hover`，`:active` 再压回一点）；点击某张卡走 `rotateTo()`——一次性把节点排到目标顺序，所以牌堆是**一次过渡**直接到那张卡展开的位置，不是逐张翻过去。注意 `cards` 现在取的是 `#deck .sheet`，不能再取 `deckEl.children`（那已经变成 stage/rail/glow 三个元素了）。
- **端点放行不回头**：到了末张再下滑、或首张再上滑时，只有页面**还没到钉住位置**（仍在上方/下方）才吸附；一旦页面越过钉住位置，手势就完全交给页面。之前末张下滑时每格都会 `scrollTo(deckTop)` 把页面拽回来，和滚动阻尼互相拉扯，表现就是卡住并抖动。
- **两端收敛**：轮播不再是无限循环。滚轮在这一屏里**只换卡、不滚页**（`preventDefault` + 需要时把页面按回 `deckTop`）；但在**第一张**时往上滚会交还给页面——扉页过渡按原样反向播放（卡片缩回缩略格、黑幕落下去），回到扉页；在**最后一张**时往下滚同样交还页面，进入工艺段。首尾各有一道边界，`rotate()` 在这两处返回 `false`。
   - 从下面回来（工艺段往上滚）时，页面先滚到这一屏附近，进入 ±180px 的窗口后由轮播接管并吸附到钉住位置，此后每滚一格**反向轮播一张**，直到第 1 张；在第 1 张继续往上才交给页面（先播收场，再走扉页过渡）。
- **点击**：点列表里任意一张 → `scrollToSheet(i)` 把页面滚到该卡进度（`offsetTop + i × --sheet-scroll`），它随即展开。
- **层级**：待看列表在展开卡**之上**（`960 - slot`），推进中的那张 `940`，展开的 `900`，已经看过的收进 `120` 并移到画面外。
- **读数**：Lights / Drop / Finish / Scale 随当前卡切换，与换图同步。
- 入场与推进都只写 `transform` / `opacity`；`prefers-reduced-motion` 下直接跳到终态。

验证脚本会启动 headless Chrome（`--remote-debugging-port=…`，`--user-data-dir=_work/chrome-profile`）。

node work/kill-headless.mjs --dry   # 先看会关掉哪些

## 三语切换（i18n.js + lang.css）
- 导航栏右侧 `.nav-end` 里注入 `.lang-switch`（EN / 中文 / العربية），当前语言带下划线高亮，选择存 `localStorage.ncl:lang`。
- **英文是源语言**：`i18n.js` 里的 `T` 以英文原文为键，值为 `[中文, العربية]`。切换时遍历文本节点与 `alt/aria-label/title/placeholder`，命中就替换并把原文记在节点上；切回英文时逐条还原。没收录的字符串保持英文，不会出现空行或 key。
- 长段落按**折叠空白后**匹配（HTML 换行不会导致漏译）。
- deck 的文案由 `main.js` 写入，走 `window.NCLtext()`，并在 `ncl:lang` 事件里重渲染。
- **阿拉伯语不镜像版式**：只换字体栈与字号；`dir` 保持 `ltr`（阿拉伯文在行内仍按 bidi 正确从右往左读）。阿拉伯字体在同样 font-size 下字形高得多，因此 `.hero-title / .craft-title / .col-hero h1 / .ach-hero h1` 都有独立的字阶与行高，否则封面标题会长高到压住导航。
- 新增词条：在 `T` 里加一行 `'English': ['中文', 'العربية']` 即可；需要整段排版级 RTL（不止 deck）时再补 `lang.css` 的镜像规则。
