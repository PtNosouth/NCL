# NCL 新构思 — 首页扉页（cover page）

独立站首页的第一屏：一支产品电影 + 导航 + 扉页文字与开场动画。**只做扉页，其余版块尚未设计。**

## 打开

```text
直接双击 index.html
```

或用本地服务（推荐）：

```text
双击 start.cmd    →    http://127.0.0.1:5174/index.html
```

`file://` 与 `http://` 两种方式均已实测：字体、视频、标志都正常。

## 结构

```text
home/
  index.html          扉页本体（NCL 标志为内联 SVG，可直接改色）
  style.css           版式、电影层、开场编排、响应式
  main.js             电影源切换、开场触发、自动循环、菜单
  media/
    ncl-70086-1080.mp4   正片（1920×1080 原生，65.1 MB，50.6 s，无音轨，crf 18 视觉无损）
    ncl-70086-720.mp4    移动端正片（1280×720，15.3 MB，crf 25）
    ncl-70086-poster.jpg 首帧海报（1920×1080，取自母版第 0 帧）
    ncl-wordmark.svg     NCL 标志母版（与页面内联版本一致，可单独给印刷/其他站点用）
  fonts/              Instrument Serif / Sora 300·400 / IBM Plex Mono
  _work/              gen_logo.py（标志生成器）、截图与验证脚本（评审证据，非页面依赖）

```

## 设计说明

**方向**：把灯具自己的光当成界面。页面从黑场与虚焦开始，画面像眼睛适应暗处那样慢慢合焦、慢慢亮起来——没有硬边、没有闪烁；标题再从同一层虚焦里升起，NCL 标志先一步落位，影片随后自动循环。

- **标志**：NCL 是用参数化生成器（`_work/gen_logo.py`）画出来的 Didone 字标，不是套字体：100 单位大写高度、竖干 14.5、发丝衬线 3、N 的斜干比竖干更宽（15.5，按视错觉补偿）、C 的外轮廓 33.5/50 与内轮廓 19.5/39.5 形成"腰部厚、末端细"的对比、L 的脚是细横并以发丝竖衬收尾。全部是 `<rect>/<path>/<polygon>`，`fill:currentColor`，页面里直接改 CSS 颜色即可；在 19–25px 的导航尺寸下仍是清晰的矢量边缘（旧位图标志在这里会糊成一团）。
- **隐喻**：橱窗 / 展签。没有进度条、没有时间码、没有播放键——片子自己循环，页面只有画面、标题与导航，不打断观看。
- **字体**：Instrument Serif（标题，仅 Regular，靠字号与极紧行距拿重量）、Sora 300（导航、说明，大字距）。中文走系统宋体栈，品牌中文名只在标志旁出现一次。
- **标题质感**：象牙字浮在黑底与鎏金画面之上，靠四层 `text-shadow` 与背景分离——顶边 1px 暖色高光（模拟上方来光）、近距遮挡阴影、中距软衰减、大距极淡晕染；`gold` 另加一层暖金晕。不是描边、不是渐变字、不是立体挤压。开场时标题从 `blur(11px)` 与 24px 位移中升起，落位后由 `body.intro-done` 撤掉合成的 `filter`，保证终态是原生锐度。
- **色彩**：黑（#000）、象牙（#efe8db）、鎏金（#c7a366）。金色只出现在三处：标志、句末的 `gold`（平涂黄铜 #e6ca94，不做渐变）、以及可交互状态的"亮起来"。
- **交互**：导航、CTA、Enquire、菜单项在悬浮时都是**字体本身亮起来**（颜色提到 #fff 并加一层暖色光晕 `text-shadow`），没有下划线、没有滑动色块、没有进度条，也没有播放控制；影片打开即自动循环。
- **素材**：原片 `assets/新构思视频/70086-8L.mp4`（1920×1080、25 fps、约 10 Mbps、60 s、带音轨）重新剪辑：去掉首尾黑场与重复的整灯空镜，把开场的晶体特写挪到片尾，因此片头就是整灯全景、循环时不再跳变。
- **画质**：桌面版按**原生 1920×1080** 输出，`crf 18`、`preset slow`、`aq-mode=3`、`deblock=-1,-1`、`+faststart`，保持原片分辨率与细节（旧版是 1600×900 + crf 27，晶体边缘和鎏金反光被抹平）。对源片实测 **Y-PSNR 41.3 dB / SSIM 0.9966**，属于视觉无损区间。移动端 1280×720 `crf 25`（15.3 MB），只为带宽让步、不再牺牲分辨率。
- **动画**：全部 CSS 关键帧，2.2 秒开场，无第三方动效库、不依赖滚动。任何指针 / 键盘 / 滚轮输入立刻跳到终态；`prefers-reduced-motion` 下不自动播放，给静态帧 + 可控播放。
- **响应式**：≥900px 全屏电影，文字压在画面左下；≤900px 导航收起为菜单，文字仍压在画面上；≤620px 电影改为"上方亮着的橱窗 + 下方黑场文案"，避免 16:9 素材在竖屏被裁成碎金。
- **删减**：没有玻璃拟态卡片、渐变按钮、缩略图条、"Welcome"式居中大标语；产品号与灯数字段已按需求删除（"Fixture No. 70086 / Eight lights"整行移除）；尺寸参数未写入（现有素材未提供 8 灯规格）。

## 评审与修订记录

第一轮独立设计评审（只看截图、不给代码）打分：层级 7、字体排印 8、构图与电影 7、色彩材质 7、克制 8、可读性与对比 6、小屏处理 5。据此改了：删掉四处无解释的角标记号；页脚章节尺从右侧竖排（压在最亮的晶体上读不清）改为底部横排；竖屏重排让整灯轮廓完整出现；手机菜单 CLOSE 改为 X 并把 Enquire 做成唯一强调项；商业事实从 11px 脚注提到正文；`gold` 由渐变裁字改平涂黄铜；页面底色改纯黑消除接缝；标志改为第一帧即出现。

客户第二轮反馈的四项调整：

1. **去掉进度条跳转**：删除六段章节尺、当前章节名与顶部进度细线（连同 `--p` 变量与全部跳转逻辑），改为纯自动循环播放；底部只留播放/暂停与时间码。
2. **重做品牌标志**：不再使用品牌位图，改为上述参数化 Didone「NCL」矢量字标。
3. **悬浮动画改为"字体亮起来"**：移除所有下划线/横线与滑动填充，改为颜色提亮 + 暖色光晕（`--glow`），标志、导航、CTA、Enquire、菜单、播放按钮统一。
4. **删除 `Fixture No. 70086 / Eight lights` 整行**；
5. **连播放/暂停键与时间码一并删除**：底部整条片尾（`.plate`）移除，`.stage` 由三行改两行，`main.js` 里的时钟与传输逻辑随之删除，影片完全自播自循环。

客户第三轮反馈的两项调整：

6. **修复 `g` 的下半截被切掉**：根因是标题逐行遮罩用的 `overflow:hidden`（`line-height:.9` 的行盒容不下降部）。没有靠加大 padding 掩盖，而是换掉手法：标题改为「虚焦升起」（`opacity + translateY + blur`），**不再需要任何裁切**，`g`、逗号、以及 `gold.` 的句点都完整显示；`_work/verify.mjs` 增加了 `.hero-title/.line` 的 `overflow` 必须为 `visible` 的回归断言，防止再犯。
7. **标题更有质感、与背景分离**：加了四层定向阴影 + 顶边暖色高光，`gold` 额外叠加暖金晕；配上升起时的 `blur` 过渡，字面有前压感。

## 画质与体积

| 版本 | 分辨率 | 编码 | 体积 | 对源片质量 |
|---|---|---|---|---|
| 桌面 `ncl-70086-1080.mp4` | 1920×1080 | x264 crf 18 | 65.1 MB | Y-PSNR 41.3 dB / SSIM 0.9966（视觉无损） |
| 备选（未使用） | 1920×1080 | x264 crf 22 | 38.7 MB | Y-PSNR 38.2 dB（近无损，肉眼几乎无差） |
| 移动 `ncl-70086-720.mp4` | 1280×720 | x264 crf 25 | 15.3 MB | 分辨率减半，细节有可察损失 |

画面仍只有一条时间线：桌面端取 1080 母版，≤900px 或慢速网络取 720 版（`main.js` 的 `pickSource()`）。若嫌 65 MB 太重，把 `pickSource()` 的桌面分支换成 crf 22 那版即可（38.7 MB），画质差别在正常观看距离下看不出来。

## 未做 / 待定

- 导航链接（Collections / Bespoke / Projects / Atelier / Enquire）与首页 CTA 指向的版块尚未建立，目前是锚点占位。
- 视频为无声版；若需要"开灯"音效或旁白，需要另加音轨，并注意浏览器要求有声播放必须有用户手势，届时需要引回一个开关。
- 按需求页面不提供播放/暂停控制，影片是 50 秒循环的动态背景。WCAG 2.2.2 对超过 5 秒的自动播放动效要求提供暂停手段，这一条目前是**已知偏离**；`prefers-reduced-motion` 下不自动播放、显示静帧，可作为折中。若后续需要合规，建议加回一个极简的播放/暂停文字按钮（约 10 行代码）。
- 未做多语言（目前英文为主、品牌中文名保留）、未做 OG 分享图、未接统计。
- 标志为单色矢量；若要烫金/渐变版本，在当前 SVG 上换 `fill` 或加 `linearGradient` 即可，字形不用改。
